# Study 2 interaction revision

3 November 2026. Study 2 app v14, state v10, event schema v12. Shared candidate material remains v7.

After every final decision the same neutral free-text question asks: "In a few words, what was the main reason for your final decision?" The native text control and workflow both enforce a 200-character cap. No candidate-specific hints, source menu or answer details are added. The existing secondary decisive-evidence outcome and independent coding plan remain unchanged. A short source-only answer is not automatically scored correct.

Both initial and final confidence ratings start unanswered. The native select-slider has a "No rating selected" position followed by integer values 0–100. Submission requires a numerical selection. A deliberate midpoint of 50 is valid; the interaction does not require participants to give a different number. New state/session identifiers distinguish this interaction from the old default-50 rehearsal records.

There is no minimum time, no participant instruction about time per profile and no automatic submission. Completion and document times remain descriptive logs. The interface introduces no 20-minute hard deadline. The full-flow duration and compensation require a separate human technical pilot; 17–18 minutes is currently an estimate, not an observed completion-time result.

The eight condition-locked apps, six cases, initial/final decisions, requirement re-entry and primary reliance analysis remain unchanged. Questionnaire item reductions, a new sample target, alternative hypothesis multiplicity and a completion-code scheme are separate proposals and were not installed by this interaction revision.

The manuscript Methods companions were changed only for the neutral prompt, response cap and explicit confidence selection. The free-text coding paragraphs remain intact. The local Qualtrics design's contradictory menu instructions were aligned to the author's latest decision. No live Qualtrics survey was edited.
